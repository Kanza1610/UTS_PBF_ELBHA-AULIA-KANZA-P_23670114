## Deskripsi

Proyek ini dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman Berbasis Framework.

Menggunakan **Paket Template Genap**, dengan implementasi 12 halaman HTML menjadi Laravel Blade:

- **Admin (Upcube):** Dashboard, Calendar, Form Elements, DataTables, SweetAlert, Login.
- **Landing Page (Restoran):** Home, About, Service, Menu, Booking, Team.

## Teknologi

- Laravel 12
- PHP 8.2
- Blade Template Engine
- HTML, CSS, JavaScript
- Bootstrap

## Cara Menjalankan

1. Clone repository dan buka folder proyek.
2. Instal dependensi:

   ```bash
   composer install
   ```

3. Salin file environment dan buat application key:

   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

4. Jalankan server:

   ```bash
   php artisan serve
   ```

Akses aplikasi melalui:

- **Landing Page:** http://127.0.0.1:8000
- **Admin:** http://127.0.0.1:8000/admin
